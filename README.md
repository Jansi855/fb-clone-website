# fb-clone-website

A simple **Facebook Website Clone** created using **HTML and CSS** as part of my Git and GitHub learning journey.

## 📖 About the Project

This project is a front-end clone of the Facebook landing page. It was developed during a Git and GitHub tutorial to practice version control concepts while building a real-world web page.

The main goal of this project was to:
- Learn the basics of Git and GitHub.
- Practice HTML and CSS.
- Understand how to create repositories, commits, branches, and push projects to GitHub.
- Build a responsive and visually appealing web page inspired by Facebook.

## 🚀 Features

- Facebook-inspired landing page
- Responsive layout
- Clean and organized HTML structure
- CSS styling for a modern UI
- Beginner-friendly project

## 🛠️ Technologies Used

- HTML5
- CSS3
- Git
- GitHub
